# Shan'do: where the lines come from

The method is the one used for the BG3 word mods: take a set of words, look each one up in real sources (here the
game, Tolkien, and spiritual and meditative practice), note what each source says, and write the lines from what
turned up. Searched 5 Nov 2026. The two Warcraft wikis and Tolkien Gateway refused direct fetches, so game and
Tolkien details come from search results quoting them; nothing below is from memory alone.

## When she speaks

Never in combat, and never within 45 seconds of the last line from her (Herbalore included).

| Moment | How often |
|---|---|
| login | once |
| a new zone | first visit each session |
| night on the server clock (21:00-05:00), outdoors | at most once an hour |
| standing still outdoors for 90 seconds | at most once every 20 minutes: a breath |
| entering an inn or a city | at most once every 30 minutes |
| on a flight | each flight |
| swimming | at most once every 20 minutes |
| dead | once per death |
| level up | each level |
